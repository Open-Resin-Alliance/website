VoxelShift v0.3.6 was published on 18 February 2026. The release notes are short and specific: `Zlib fixes` by PaulGD03, merged as pull request 3. The tag is at [github.com/Open-Resin-Alliance/VoxelShift/releases/tag/v0.3.6](https://github.com/Open-Resin-Alliance/VoxelShift/releases/tag/v0.3.6).

The fix lands after a compressed release cycle. VoxelShift's first release, v0.2.0 "Initial Release", appeared on 14 February 2026, the same day the repository was created, and three more named releases followed within five days.

## Release history

- **v0.2.0, Initial Release**, 14 February 2026. The first public build of the CTB, CBDDLP, and Photon to NanoDLP converter.
- **v0.3.0, Massive Optimization**, 15 February 2026. The project's own summary: "Massive Optimization and refinement of post-processing mode. Now using a C-based FFI, including GPU usage. CUDA is being explored too, but currently unusable due to memory issues."
- **v0.3.2, macOS Support**, 15 February 2026. The desktop utility gained a macOS build.
- **v0.3.6, zlib fixes**, 18 February 2026. The current release, fixing compression handling in the converted output.

Intermediate tags between these, including v0.3.3, v0.3.4, and v0.3.5, were published on 15 and 16 February 2026 as the optimisation work settled.

## Platform support

The README documents a deliberately honest support matrix:

- **Windows**: supported and tested.
- **macOS**: supported and tested.
- **Linux**: supported but not tested.
- **Web, Android, and iOS**: not supported and not tested.

The v0.3.6 release assets match that: a Windows MSI installer, a macOS `.dmg`, and a macOS `.zip`. Linux users can build from source, but should expect to be the first to encounter any platform-specific problems.

## Notes for users

VoxelShift works on files produced by other slicers, so results depend on the range of files it has seen. If a conversion misbehaves, the most useful report includes the source format, the producing slicer, and the resulting `.nanodlp` archive. The post-processor mode can be wired into a slicer as an external tool, and the README documents a family of `VOXELSHIFT_` environment variables for tuning GPU use and recompression behaviour.

VoxelShift is licensed under the Apache License 2.0 and is independent of the file formats it reads: no vendor affiliation is implied by support for a given format or printer.

## Get involved

If you print from NanoDLP and hit a file that does not convert, that report is a contribution in itself. Open an issue on the [VoxelShift repository](https://github.com/Open-Resin-Alliance/VoxelShift) with a sample and a description, or bring it to the [Open Resin Alliance Discord](https://discord.gg/beFeTaPH6v) where the format work is discussed.
