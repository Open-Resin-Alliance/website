DragonFruit v0.1.15 was published on 29 August 2026 as a dev build. The tag is at [github.com/Open-Resin-Alliance/DragonFruit/releases/tag/v0.1.15](https://github.com/Open-Resin-Alliance/DragonFruit/releases/tag/v0.1.15).

## What a dev build is

DragonFruit ships development snapshots rather than stable releases. Each one carries the same standing disclaimer:

> v0.1.15 is a dev build, i.e. a snapshot of the `dev` branch, and it's the bleeding edge of DragonFruit development. We regularly release them to show feature previews, bug fixes, and to stabilize the dev tree towards the next stable release. We firmly believe in development in the open.

Every DragonFruit release published so far is marked as a prerelease. There is no stable build to download yet; v0.2.0 is the release the notes describe as "the expected stable".

## Auto-supports v1.5

The first of the two changes in this build is the second iteration of automatic support generation, informed by what printing the first version taught the team. The release notes describe it this way:

> Auto-Supports v1.5: automatic support generation rebuilt on what printing V1 taught us. Distribution is now a single fixed-density scheme: a boundary ring plus grid infill per overhang region, resolved against the real triangles instead of the voxel mask.

The practical consequence is a simpler distribution rule coupled to more faithful geometry. Instead of planning supports against a voxelised approximation of the model, the generator resolves them against the actual triangles of each overhang region, with a boundary ring around the edge and a grid inside it.

## Linux renders again

The second change repairs a regression introduced in v0.1.14, where Linux users saw a blank build plate. The cause, as documented in the release notes:

> Linux renders again: the blank build plate in 0.1.14 was the splash screen asking for a transparent window, which crashes the GPU process under CEF and takes every WebGL context in that process down with it, including the main window's.

In other words, the failure was not in the renderer but in the window the splash screen requested. Fixing it restores every WebGL surface in the affected process, not just the splash.

## Builds and credits

The v0.1.15 downloads cover the desktop targets the project currently ships: a Windows x64 installer, a universal macOS `.dmg`, an x86-64 Flatpak, and a macOS `DragonFruit.app.tar.gz`, alongside signature files and a `latest-dev.json` manifest for update checks. Version 0.1.15 also added a sponsors carousel under Settings, which aggregates live backers from Open Collective, and it credits contributors PaulGD03 and Jo-Con-El.
